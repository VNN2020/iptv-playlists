# IPTV Playlists

Free M3U playlists for IPTV players (IPTV Smarters Pro, VLC, TiviMate, Kodi).

## football-soccer.m3u

40 football/soccer channels — beIN Sports, ESPN (US/LatAm/Brazil), Fox Sports,
Sky Sports, Eleven Sports, Fubo Sports Network, CBS Sports Golazo, Match!,
TyC Sports, and more.

**Load in a player:**

```
https://raw.githubusercontent.com/VNN2020/iptv-playlists/main/football-soccer.m3u
```

**In IPTV Smarters Pro:** LOAD YOUR PLAYLIST OR FILE/URL → name it →
select **M3U URL** → paste the URL above → ADD USER.

## Source

Channels are drawn from the public [iptv-org](https://github.com/iptv-org/iptv)
project and filtered to sports networks that carry football/soccer. Streams are
verified live before inclusion.

These are free, publicly-available streams. Availability changes without notice
and some sources may be unofficial re-streams. No warranty is given.
